# Barkside Boarding & Spa

A full-stack pet boarding and grooming web app built with Node.js, Express, MongoDB (Mongoose) and a vanilla JS/HTML/CSS front end.

## Features

- **Admit Pets** (dogs & cats) with optional spa services  
- **Capacity Limits** (5 dogs, 5 cats) with waitlist & phone-back modal  
- **Search**, **Sort**, and **Filter** active pets  
- **Check Out** pets (mark as “checked out”)  
- **Manage Waitlist** (add, remove, admit)
